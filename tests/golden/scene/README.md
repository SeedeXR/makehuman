# Scene fixtures

`two_cubes.glb` — two identical cubes at node translations x = -5 and x = +5.

Their geometry is identical; the **only** thing distinguishing them in the file
is the node transform. An importer that reads `aiScene::mMeshes` directly and
never walks `mRootNode` returns both at the origin, silently, with no error —
which is precisely the bug this fixture exists to catch.

Generated by `tools/make_scene_fixture.py` (Blender). Two primitive cubes, no
third-party asset, CC0 like the rest of the tree.
